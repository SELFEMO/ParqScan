使用说明

ParqScan 是面向 Parquet、嵌入图片和二进制附件的桌面检查与转换工具。以下说明与 README 一致，侧重日常操作。

安装与运行

克隆或下载仓库后，在项目根目录安装依赖并启动：

python -m pip install -r requirements.txt
python main.py

也可在启动时传入文件路径：

python main.py sample.parquet

主要依赖：PySide6、PyArrow、openpyxl、psutil。

打开文件

支持文件菜单、拖拽到主窗口、最近文件列表，以及命令行参数。可同时打开多个文件，在侧栏切换工作区。

浏览与搜索

数据预览使用固定分页，默认每页 20 行。Ctrl+F 可在「文件级搜索」与「当前页搜索」之间切换——两者状态独立，不会互相覆盖。

当前页筛选只作用于可见行；文件搜索完成后不会自动清除筛选。列头排序会扫描整个文件建立行号索引。

记录详情

单击选中整行；双击任意单元格打开该行的完整详情。左侧多选字段，右侧画布按格显示；新格叠在 (0,0) 并置顶。字符串 JSON 在详情中按层级缩进显示，不改变导出语义。

图片预览

识别 JPEG、PNG、BMP、GIF、WEBP、TIFF、ICO、data URI 与校验过的 Base64，包括嵌套 binary 字段。表格显示缩略图；悬停显示较大预览；详情中可缩放查看完整原图。

原始字节

在详情中选择二进制字段，或在数据表右键「查看原始字节」，打开 Hex + ASCII 视图。支持自动、Hex 字节、文本与偏移地址搜索；需点击「搜索」按钮执行定位。

导出格式

通过文件菜单导出：

  • CSV
  • JSON
  • Excel
  • Markdown
  • SQL
  • Parquet 碎片
  • 另可批量提取当前文件中的嵌入图片到指定目录。

可移植配置

默认配置保存在用户应用数据目录。在程序目录放置空文件 portable.flag 后，分页大小、主题、语言、最近文件与列顺序会保存在程序目录旁。

portable.flag

打包

Windows 推荐通过 GitHub Release 下载 ParqScan-Windows-Setup.exe 安装包。开发者可在 Windows 上运行 python build.py --installer 生成安装包；也可仅打包为 dist/ParqScan/ParqScan.exe（目录模式）或使用 --onefile。启动失败可查看用户应用数据目录 ParqScan/logs/startup.log。

python build.py
python build.py --installer
python build.py --onefile

每次只读一页 Parquet

ParqScan 不把整份大文件物化进内存。数据预览采用固定分页，模型只保留当前页；翻页时才从磁盘读取下一窗口。

三个机制

固定分页读取

每页 20、50、100 或 200 行可选。翻页、改页大小或关闭文档会释放旧页与缩略图缓存；后台任务用代次隔离，过期结果不能覆盖当前页。

图片按需解码

表格用 72px 缩略图与 520px 悬停预览；完整原图只在打开记录详情时解码。缩放只改视图矩阵，不重复解码。

嵌套 binary 与 Hex

递归识别 struct、list、map 中的 binary 叶子。非图片载荷可在详情或右键菜单中打开 Hex + ASCII 搜索，支持按字节、文本或偏移定位。

浏览与搜索

元数据、Schema、行组统计；文件级与当前页搜索分离；列可拖动并持久化顺序。

双击任意单元格打开整行详情；多字段可叠放在自由画布上，图片支持缩放与平移。

典型路径

  1. 打开 Parquet 文件（对话框、拖拽、最近文件或命令行）
  2. 在元数据页查看 Schema、压缩与行组
  3. 在数据预览页翻页浏览，必要时搜索或筛选当前页
  4. 双击行打开详情，或右键查看原始字节
  5. 导出数据或提取图片

快速安装

需要 Python 3 与 requirements.txt 中的依赖（PySide6、PyArrow、openpyxl、psutil）。

python -m pip install -r requirements.txt
python main.py

打开指定文件：

python main.py sample.parquet
